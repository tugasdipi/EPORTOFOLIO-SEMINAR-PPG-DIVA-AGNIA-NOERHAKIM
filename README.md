## Deploy ke GitHub Pages
1. Ekstrak ZIP ini.
2. Upload `index.html`, `README.md`, dan `.nojekyll` ke root repository GitHub.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Klik **Save**.

Versi ini sudah dioptimasi agar ukuran `index.html` jauh lebih kecil dan lebih aman untuk upload melalui GitHub web.
